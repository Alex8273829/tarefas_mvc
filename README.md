# Gerenciador de tarefas

    Este projeto servirá para aprimorarmos nossa lógica
    de programação ao mesmo tempo que exploramos conceitos
    e técnicas de programação back-end e fullstack. Vamos 
    utilizar e desenvolver o conceito de MVC, algumas 
    particularidades da Programação Orientada a Objetos,
    Programação Funcional, persistência de dados, 
    microframework Flask e gerenciador de pacotes do
    Python (astral uv).
